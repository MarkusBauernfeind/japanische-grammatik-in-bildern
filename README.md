# Warum に kein Dativ ist — Japanische Grammatik in Bildern

Ein Lehrwerk für Japanisch-Lernende, das japanische Partikel und Verbformen nicht in deutsche Grammatikkategorien presst, sondern über das innere Bild vermittelt, das japanischen Sprechern naheliegt.

## Inhalt

45 Kapitel: 24 Partikel, ein Sammelkapitel zu den Verb-Stammformen, 14 funktionale Formen (ないForm, たいForm, ますForm, etc.), sowie Tatbestand, Höflichkeitsformen, Adjektive, Nomen, Adverbien und Geben/Bekommen (あげる/くれる/もらう).
